การใช้งาน Try-Catch
กับ String ใน Java

เรียนรู้การดักจับข้อผิดพลาดตั้งแต่พื้นฐานจนถึงการ throw exception ออกจาก method

ระดับ 1

Try-Catch แบบพื้นฐาน

เมื่อเราพยายาม parse String ที่ไม่ใช่ตัวเลขให้เป็น int Java จะโยน NumberFormatException ออกมา เราใช้ try-catch เพื่อรับมือแทนที่จะให้โปรแกรมพัง
BasicTryCatch.java 
public class BasicTryCatch {
    public static void main(String[] args) {

        String input = "hello";  // ไม่ใช่ตัวเลข!

        try {
            // พยายาม parse String → int
            int number = Integer.parseInt(input);
            System.out.println("ตัวเลขคือ: " + number);

        } catch (NumberFormatException e) {
            // จะมาที่นี่เมื่อ parse ไม่ได้
            System.out.println("Error: แปลงเป็นตัวเลขไม่ได้ → " + e.getMessage());
        }

        System.out.println("โปรแกรมยังทำงานต่อได้ปกติ ✓");
    }
}
Output
Error: แปลงเป็นตัวเลขไม่ได้ → For input string: "hello"
โปรแกรมยังทำงานต่อได้ปกติ ✓
💡 โค้ดใน try { } จะหยุดทันทีที่เกิด error แล้ว "กระโดด" มาที่ catch { } บรรทัดหลัง try-catch จะยังทำงานต่อตามปกติ เพราะเราดักจับ error ไว้แล้ว
ระดับ 2

ดักหลาย Exception พร้อมกัน

ในชีวิตจริง String อาจเป็น null หรืออาจเข้าถึงตำแหน่งที่ไม่มีใน array เราวาง catch ได้หลายบล็อก เพื่อจัดการแต่ละกรณีต่างกัน
MultiCatch.java 
public class MultiCatch {
    public static void main(String[] args) {

        String[] words = {"Java", "Exception", null};

        try {
            // ① ลองเข้าถึง index ที่ไม่มี → ArrayIndexOutOfBoundsException
            String word = words[10];

            // ② ถ้า word เป็น null แล้วเรียก method → NullPointerException
            System.out.println(word.toUpperCase());

            // ③ ถ้า word เป็น String ที่ไม่ใช่ตัวเลข → NumberFormatException
            int num = Integer.parseInt(word);

        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("[ArrayIndex] ไม่มี index นั้นใน array!");
            System.out.println("  → " + e.getMessage());

        } catch (NullPointerException e) {
            System.out.println("[Null] ค่าเป็น null เรียก method ไม่ได้!");

        } catch (NumberFormatException e) {
            System.out.println("[NumberFormat] แปลงตัวเลขไม่ได้!");

        } finally {
            // finally ทำงานเสมอ ไม่ว่าจะเกิด error หรือไม่
            System.out.println("[finally] จบการทำงาน");
        }
    }
}
Output (index 10 ไม่มีใน array ขนาด 3)
[ArrayIndex] ไม่มี index นั้นใน array!
→ Index 10 out of bounds for length 3
[finally] จบการทำงาน
⚠️ Java จะเข้า catch บล็อกแรกที่ "ตรงกับ" ชนิด exception แล้วข้ามบล็อกที่เหลือ ลำดับสำคัญมาก — วาง exception ที่ละเอียดกว่า (เฉพาะเจาะจงกว่า) ไว้บนสุดเสมอ
✅ ลองเปลี่ยน index จาก 10 → 2 เพื่อดูว่าจะเกิด NullPointerException แทน เพราะ words[2] คือ null
ระดับ 3

Throw Exception ออกจาก Method

บางครั้งเราอยากให้ method "ปฏิเสธ" input ที่ผิดกฎเอง เช่น ห้ามให้ชื่อว่าง หรือห้ามชื่อสั้นเกินไป เราใช้ throw เพื่อโยน exception กลับไปให้ผู้เรียก
StringValidator.java 
public class StringValidator {

    // ── method ที่ throw exception ออกไป ──────────────────

    public static String validateName(String name)
            throws IllegalArgumentException {

        if (name == null) {
            throw new IllegalArgumentException("ชื่อต้องไม่เป็น null");
        }
        if (name.isBlank()) {
            throw new IllegalArgumentException("ชื่อต้องไม่เป็นค่าว่าง");
        }
        if (name.length() < 3) {
            throw new IllegalArgumentException(
                "ชื่อต้องมีอย่างน้อย 3 ตัวอักษร (ได้ " + name.length() + ")"
            );
        }

        // ผ่านทุกเงื่อนไข → คืนค่าชื่อที่ trim แล้ว
        return name.trim().toUpperCase();
    }

    // ── ทดสอบ ──────────────────────────────────────────────

    public static void main(String[] args) {

        String[] testCases = {"Alice", "  ", "Bo", null, "Charlie"};

        for (String name : testCases) {
            try {
                String result = validateName(name);
                System.out.println("✓ ชื่อที่ผ่านการตรวจ: " + result);

            } catch (IllegalArgumentException e) {
                System.out.println("✗ ข้อมูล [" + name + "] → " + e.getMessage());
            }
        }
    }
}
Output
✓ ชื่อที่ผ่านการตรวจ: ALICE
✗ ข้อมูล [ ] → ชื่อต้องไม่เป็นค่าว่าง
✗ ข้อมูล [Bo] → ชื่อต้องมีอย่างน้อย 3 ตัวอักษร (ได้ 2)
✗ ข้อมูล [null] → ชื่อต้องไม่เป็น null
✓ ชื่อที่ผ่านการตรวจ: CHARLIE
🔑
throws vs throw
throws (พหูพจน์) ใส่ไว้ที่ signature ของ method เพื่อ "ประกาศ" ว่าอาจโยน exception ใดออกไป
throw (เอกพจน์) คือคำสั่งจริง ๆ ที่สร้างและโยน exception ออกไปในขณะนั้น

สรุปโครงสร้าง Try-Catch

structure.java 
try {
    // โค้ดที่อาจเกิด error

} catch (SpecificException e) {
    // จัดการ error ชนิดนี้โดยเฉพาะ

} catch (AnotherException | YetAnother e) {
    // จัดการหลาย exception ด้วย catch เดียว (Java 7+)

} catch (Exception e) {
    // ดักทุก exception ที่เหลือ (วางไว้ล่างสุด)

} finally {
    // ทำงานเสมอ — ใช้ปิด file, database connection ฯลฯ
}
📌 Exception ที่พบบ่อยกับ String: NullPointerException (String เป็น null), ArrayIndexOutOfBoundsException (index เกินขนาด), NumberFormatException (parse ตัวเลขจาก String ไม่ได้), StringIndexOutOfBoundsException (charAt/substring เกินความยาว String)
